此文件记录公开草稿的当前状态，供之后复查。源码公开与把服务开放给其他人访问是两件事。

## 已核对

- 草稿没有复制数据库、聊天图片、笔记图片、电子书、真实 `.env`、旧 Git 历史或部署报告。审查时发现并移除了一个含具体关系经历示例的旧记忆迁移预览脚本。

## 源码参考与联网部署的边界

- 作为架构参考公开源码，不要求先为所有人的服务器环境实现统一部署方案。
- 若自行将服务开放到公网，必须先保护网关 API 与 Admin 接口。当前前端口令只是浏览器中的演示门，不保护 API；不要直接对公网开放网关。身份验证、HTTPS、反向代理、备份及域名配置应按实际环境完成并验证。
- M-Home 自有源码和文档采用 [MIT 许可证](../LICENSE)。第三方依赖各自的许可继续适用。

## 仍需后续处理的实现限制

- **辅助模块协议未统一**：共读、笔记直接用兼容 Chat Completions；每日总结也没有沿用即时摘要的完整协议分支。前端已支持某提供商，不代表所有后台模块都支持同样的协议。

- **部署范围**：单用户、单网关进程；前端演示门、服务端身份验证和多人数据隔离的边界保持上述说明。
