# 配置与数据说明

M-Home 当前按一位用户和一位助手设计：不同对话窗口共用画像、记忆与摘要。API 账户下拉框是服务切换器，不是用户账户系统；请勿把这份代码直接当成多个用户之间资料隔离的服务。

## 模型分别在哪里配置

| 用途 | 配置位置 | 说明 |
| --- | --- | --- |
| 网页聊天 | 前端设置的 API Key、模型、网关地址 | API 账户保存在当前浏览器的 localStorage；发起聊天时 Key 会传给所配置的网关，再用于请求模型服务。网关地址应由部署者控制。 |
| 共读批注、笔记评论 | `gateway/.env` 中的 `MAIN_*` | 不随前端账户切换。目前直接调用 OpenAI 兼容的 `/chat/completions`，仅修改 `MAIN_API_PROVIDER` 不会把这些模块切到 Anthropic 原生协议。 |
| 即时摘要、每日总结、快照及部分记忆判断 | `SUMMARY_*`、`MEMORY_JUDGE_MODEL` | 即时摘要有 Anthropic 分支；每日总结等路径仍使用兼容接口。初次配置整套功能时，使用兼容 `/chat/completions` 的服务。 |
| 图片描述与笔记图片理解 | `VL_*` | 需要支持图片输入的兼容接口；聊天的直接看图路径与此不同。 |
| 候选图画室 | `ART_IMAGE_*`、`ART_REVIEW_MODEL` 与审稿所用后端的 Key | 生图和审稿是不同请求。前端聊天 Key 不会自动填入所有后台任务配置。 |
| 可选语义检索 | `EMBEDDING_*` | 默认关闭；开启时填写支持 embeddings 的地址、Key 和模型。 |

示例中的 `your-...-model-id` 必须替换为服务方实际提供的模型标识。不同渠道可能使用不同前缀；这些是占位符，不是可直接调用的模型名。前端的网关地址指向 M-Home 后端，不是模型供应商地址。

## 数据与备份

默认数据位于 `gateway/data/`，可通过 `DATA_DIR` 改位置；单独指定的数据库或图片目录会覆盖该默认值。备份应同时包括 SQLite 数据库、聊天/笔记/画室图片和电子书目录；只有数据库不能恢复图片文件。最简单的一致备份方式是停止网关后复制整个数据目录及另行配置的数据路径。浏览器里的 API 账户和本地界面偏好需要另行处理，它们不在服务器数据库中。

后台任务和每日归档使用服务器进程的本地时间；改变电脑浏览器时区不会改变服务器的归档时点。建议先使用单个网关进程：摘要队列和部分后台任务含进程内状态，目前没有多进程协调机制。

每日归档从 SQLite 读取最近 7 个已结束的服务器本地日期，跨午夜的一轮按助手回复入库日期归属。启动或定时检查时会补上缺失的日期，已有日总结保留。归档和近况快照分别记录进度，失败延迟 30 分钟重试。超过 7 天的日总结缺口不自动补齐，已经生成的日总结仍可用于重试快照。即时摘要继续使用独立的重启恢复机制。

## 准备上传源码

只将公开草稿作为新仓库内容上传，使用新的 Git 历史。不要把上一级私人项目或原有历史一起上传。`.gitignore` 排除了常见数据和构建目录，但直接打包整个文件夹仍会包含被忽略的文件；上传前应查看实际待提交文件列表。真实 `.env`、数据库、图片、电子书、日志、浏览器数据与临时测试环境不属于公开内容。
