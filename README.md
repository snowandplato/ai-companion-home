# M-Home

一个情感陪伴类 AI 应用的架构与实现参考。代码包含对话、记忆、共读、笔记和画室等模块；它并非一键部署产品，使用者需要根据自己的模型服务、服务器和访问方式调整配置。

## 这里有什么

- **对话**：保存多窗口聊天记录，支持历史消息分段加载、搜索、图片消息和两种回复样式。
- **记忆**：组合手写设定、用户画像、近期摘要和长期记忆；助手也可以主动查阅相关记忆。
- **画室**：用 Claude 等未接入原生生图的模型聊天时，也可以让助手自主构思。独立生图服务负责生成候选图，再由助手看图、决定是否重画或发表作品。支持原生生图的 OpenAI 主模型也可以在同一轮直接作画。
- **共读与笔记**：阅读 EPUB、留下批注；保存图文笔记并生成助手评论。

**用户画像**记录助手在长期交流中逐渐形成的认识，例如用户怎样做判断、在关系中看重什么。开启自动维护后，助手可以在对话中修正已有判断，或补上一个新维度。画像按固定栏目保存，用户可以在后台查看和编辑。

**助手便签**是助手写给未来自己的提醒。助手可以在普通聊天中主动留下一条第一人称便签，记住一种回应偏好、相处方式或对关系的新发现。后续对话会读到最近的便签。用户可以在「我们」页阅读，也可以在后台补充或删除。

各功能的使用方式、数据流和代码入口见[功能与架构](docs/功能与架构.md)。

模型分工、单用户范围、数据备份与上传范围见[配置与数据说明](docs/配置与数据说明.md)。

Mav 和岚是默认的示例称呼，可以在前端「称呼设置」里修改。「我们」页的小本本标题和说明会跟随助手称呼。原有手绘加载心形和应用图标已换成通用素材。生产登录口令、域名、公网 IP 和服务器路径均已改成示例配置。

本仓库不包含真实数据库、聊天记录、画像、System Core 正文、笔记、记忆、上传图片、私有 `.env` 或原项目 Git 历史。依赖与构建目录已加入忽略列表。

第一次了解配置可看 [System Core 与 Profiles 填写示例](docs/填写示例.md)；它们只是写法参考，不会自动成为用户资料。本机试运行步骤见[本地试运行](docs/本地试运行.md)。

**联网部署前请先处理访问保护。** 当前前端口令只是浏览器里的演示门，不能保护网关 API 和大部分管理接口。不要直接把网关端口开放到公网；请根据自己的环境配置服务器端身份验证、HTTPS 与访问边界。详见[检查记录](docs/发布前检查.md)。
